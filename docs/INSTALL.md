# 安装、更新与排查

适用于桌面版 Chrome。无需应用商店或开发者注册账号；这是使用开发者模式加载文件夹的手动分发版，不提供自动更新。

## 首次安装

1. 打开 https://github.com/xleft/xiaoheihe-community-enhancer/releases/latest 。
2. 展开 **Assets**，下载 `xiaoheihe-community-enhancer-0.7.3.zip`。`Source code (zip)` 是 GitHub 自动打包的整个源码仓库，新用户优先选择上述安装包。
3. 解压到长期保留的目录，例如自己创建的“浏览器扩展/小黑盒体验优化”文件夹。不要直接在压缩包预览窗口里安装。
4. 进入解压文件夹，确认直接能看到 `manifest.json`、`src`、`popup`、`icons`。
5. 在 Chrome 地址栏输入 `chrome://extensions` 并回车。
6. 开启右上角 **开发者模式**，点击 **加载已解压的扩展程序**。
7. 选择第 4 步中包含 `manifest.json` 的文件夹。若提示找不到清单，通常是选了外层目录，再进入一层查看。
8. 打开或刷新小黑盒网页版。在工具栏拼图形的扩展菜单中找到“小黑盒社区体验优化”，可选择固定到工具栏。
9. 点击扩展图标，打开“小黑盒体验设置”。默认开启全部增强，帖子默认前台新标签、评论默认当前页弹窗。

安装不要求输入 Google 或小黑盒密码。网站评论等功能仍取决于网站原有登录状态。安装后请保留目录位置；加载后的目录会被 Chrome 继续读取。

## 更新现有手动安装

只有在你决定替换同一份安装、且该目录不需要作为独立旧版保留时，才原地更新。这样更容易保留扩展身份和本地设置：

1. 先在 `chrome://extensions` 确认目标扩展及其当前加载路径，并备份该目录。
2. 从本仓库 Release 下载新安装包，先解压到临时位置核对版本。
3. 将新包中的运行文件复制到**已确认的当前加载目录**。不要根据旧文档中的机器路径猜目录，也不要覆盖其它独立保存的历史版本。
4. 返回扩展管理页，点击该扩展的重新加载按钮。
5. 刷新已经打开的小黑盒网页，打开设置面板核对版本号及开关。

如果旧版需要独立保留，请保留其目录不动，先停用旧副本，再点击“加载已解压的扩展程序”，选择独立的新版目录。不要点击旧扩展的“重新加载”来加载新目录，那仍会读取旧路径。加载路径改变可能导致扩展 ID 改变，设置也可能不会迁移。不要同时启用两个版本。

## 暂停和卸载

- 只暂停新的交互增强：在面板关闭“启用扩展”；需要时重新开启。总开关不停止当前页面中的列表响应读取与图片地址内存缓存，也不清除已经保存的帖子返回来源记录。
- 停止整个扩展处理：在 `chrome://extensions` 关闭该扩展，并刷新小黑盒网页。
- 卸载：在管理页点击“移除”，再刷新小黑盒网页；不再使用时可自行删除原加载文件夹。移除扩展会清除其本地设置。

## 常见问题

**没有“加载已解压的扩展程序”？**

先打开开发者模式。受单位或学校管理的浏览器可能被策略禁止加载，需遵循其管理规则。

**拖拽 ZIP 没有安装成功？**

本项目按“解压后加载文件夹”安装，不以拖拽 ZIP / CRX 安装为教程路径。

**安装后网页没有变化？**

刷新原先已经打开的小黑盒网页，确认浏览器给了扩展在小黑盒域名的访问权限，并检查总开关及对应功能。内容脚本需在页面重载后重新注入；加载扩展的完成提示不等于页面功能已经验收。

**为什么有开发者模式提示、不能自动更新？**

这是本地加载扩展的分发方式，没有上架应用商店。浏览器可能提示使用开发者扩展；更新需要手动下载并按上面的“原地更新”或“独立目录加载”方式处理。

**为什么第 4 张图片仍然看不到？**

需要开启图片查看器及自动补全，且页面已经收到可匹配到该帖子的列表数据。网络失败、数据缺失、紧凑卡片或网站改版都可能影响补图。可尝试重新加载失败图片或刷新网站页面；扩展不承诺绕过网站限制取得图片。

**能用于手机 App、Chrome 手机端或 Firefox 吗？**

不能按本教程安装。当前是 Chrome Manifest V3 桌面网页扩展，其它 Chromium 浏览器未逐一验证。

**Chrome 提示扩展错误怎么办？**

可先关闭对应增强或停用扩展。在 https://github.com/xleft/xiaoheihe-community-enhancer/issues 提供浏览器版本、扩展版本、页面类型和复现步骤；截图先遮挡账号、私信等私人信息，勿提交 Cookie 或凭据。
