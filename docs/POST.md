# 给小黑盒网页版做了个小扩展：帖子在旁边开，看图评论少跳转

平时用电脑逛小黑盒，我最想保留的是当前这条列表：看到一篇想读的帖子，打开、看完，再接着往下刷，不用反复找刚才的位置。

所以做了一个自己用的小工具，叫「小黑盒社区体验优化」。现在把 0.7.2 整理开源，分享给同样在电脑上逛社区的盒友。它是非官方的 Chrome 扩展，目前通过 GitHub 下载后手动安装。

【配图 1：01-overview.png｜功能总览与设置面板本地预览】

## 1. 帖子在旁边打开，列表留在原处

普通左键点帖子，可以在当前标签右边打开一个新标签。默认打开后切过去看，也能改成后台打开，先把想看的内容留着。

“关闭帖子后返回列表”可以独立开关。开启时，关闭扩展打开的帖子会尝试回到来源标签；前提是那个标签还在。它保留的是原来的页面，不是给列表做快照，网站自己刷新后不保证恢复原位置。

【配图 2：02-tabs.png｜相邻标签打开与返回来源的功能示意】

## 2. 在当前页看图，多图尝试补齐

点完整帖子卡里的正文图片，会在当前页打开图片查看器。左右按钮、键盘方向键切图，Esc 退出；普通图支持滚轮缩放和拖动，长图可以滚动阅读。

列表明确显示超过 3 张图时，扩展会从网页已经收到的列表数据里，尝试补入第 4 张以及后面的图片。不是所有帖子都保证补齐：网页没返回对应数据、网络失败或卡片结构不支持时，仍可能看不到后续图，失败的图片可以重试。

【配图 3：03-images.png｜查看器与多图补全示意，非真实站点截图】

## 3. 评论也可以留在当前页

点评论区域可以弹窗加载网站原生评论页，关掉后继续刷列表；如果更习惯网站自己的打开方式，也能在面板切回原生。

这里仍使用小黑盒原来的登录状态和评论页面，不是额外做了一套评论系统。网站加载失败或改版时，这项功能也可能受影响。

## 4. 想用哪些增强，自己开关

设置面板里有：总开关、帖子前台 / 后台 / 原生模式、关闭后返回来源、图片查看器、多图补全、评论模式和恢复默认。改完自动保存。

点赞、头像、用户名、更多菜单、搜索筛选、播放器和输入控件保留原生操作；Ctrl / Command 等修饰键和中键点击也保留浏览器习惯。本版没有自动点赞、自动评论或批量操作。

## 怎么安装

不用注册 Google / Chrome 插件开发者账号，桌面版 Chrome 可以用开发者模式手动加载：

1. 打开下面的 GitHub 下载页，在 Assets 里下载 `xiaoheihe-community-enhancer-0.7.2.zip`。
2. 解压到一个长期保留的文件夹，确认里面有 `manifest.json`。
3. 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择刚才的文件夹。
5. 刷新已经打开的小黑盒网页，在工具栏打开插件设置。

【配图 4：04-install.png｜手动安装步骤示意】

安装包不能直接当 ZIP 加载，必须先解压。装好后别删掉那个文件夹；加载或更新时需要开启开发者模式。这种分发方式没有自动更新，后面要手动下载新版再按教程更新。浏览器可能提示正在使用开发者扩展，受管理的浏览器也可能限制安装。

## 最后说明一下

这是个人非官方工具，采用 MIT 许可，欢迎看源码、提问题。当前代码没有接入作者服务器、广告或统计；设置保存在浏览器本机。网站仍会产生原有网络请求，看图和预加载也可能增加图片资源请求。

总开关暂停新的交互增强，不停止当前页读取列表响应和缓存图片地址；已打开帖子的返回来源记录也不会被开关撤销。需要完全停止时，在 Chrome 扩展管理页停用并刷新网页。

目前面向桌面版 Chrome，不适用于手机 App 或 Chrome 手机端。0.7.2 已通过包内 7 组测试和原有 17 个 JavaScript 文件语法检查；本次公开整理没有重新做真实站点安装验收，所以不承诺所有页面都正常。配图中的面板是本地预览，其余是功能与安装示意。

遇到问题可以在 GitHub Issues 里带上浏览器版本、扩展版本、页面类型和复现步骤。截图记得挡住私人信息，不要发 Cookie 或登录凭据。

如果你也想在电脑上刷列表时少来回跳转，可以按自己的需要试试，有问题随时反馈。
